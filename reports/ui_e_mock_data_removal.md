# Workstream 2: Mock Data Removal

## Objective
Remove all hardcoded `FeatureCollection` dummy arrays and placeholder structures.

## Audit Findings
A search of `src/frontend/app.js` revealed:
- `Mock Climate Zone Overlay`: Used a hardcoded single-polygon `FeatureCollection` representing `NYC-Z-1`.
- `Mock Wake Geometry`: Used an `Array.from({ length: 1000 })` block feeding a `deck.ScatterplotLayer` with random Math.random() coordinates.
- `Confidence Layer`: Used a hardcoded dummy polygon.
- `Corridors Layer`: Used a static 2-point array `[-74.0, 40.7]`.

## Resolution
Every instance of static JavaScript dummy data was completely ripped out and replaced with standard `deck.GeoJsonLayer` implementations mapped to the actual `.geojson` outputs generated by the Python scientific pipelines. All mock layers are dead.
